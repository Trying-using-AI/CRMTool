REST API (Server-side)
Call from your backend whenever a user action occurs. Recommended for all transactional events.
Endpoint
POST  https://pingcrm-tau.vercel.app/api/ingest-event
Required body fields
workspace_id — 00000000-0000-0000-0000-000000000001
user_id — phone number of the contact (e.g. 9876543210)
event — event name string
properties — any key/value object (optional)
Example — fire an event via cURL
# Paste this in your terminal to test curl -X POST https://pingcrm-tau.vercel.app/api/ingest-event \ -H "Content-Type: application/json" \ -d '{ "workspace_id": "00000000-0000-0000-0000-000000000001", "user_id": "9876543210", "event": "coupon_clicked", "properties": { "phone": "9876543210", "coupon_code": "SAVE20", "product_id": "P-991" } }'
Response:  {"ok":true,"event":"coupon_clicked","rules_applied":0}
HTTP 200 = ingested · HTTP 400 = missing fields · No auth key needed by default

SMS Vendor Setup
PingCRM supports MSG91, Twilio, Gupshup, and any custom REST vendor. Follow the guide for your chosen provider.

MSG91
Best for India · DLT compliant · Cheapest route
▼
1
Create a MSG91 account
Go to msg91.com and sign up. Verify your phone number.
2
Complete DLT registration (mandatory for India)
Register on TRAI's DLT portal (trai.gov.in). You need: business PAN, GST, and authorisation letter. MSG91 can assist — use their DLT support option. Takes 2–5 days.
3
Register your Sender ID (Header)

4
Register your DLT Template
In MSG91 → DLT Templates → Add template. Copy the Template ID — you'll need it when creating campaigns. Use {{var}} for variables.
5
Get your API Key
MSG91 Dashboard → API → copy your Auth Key. Keep it secret.
6
Add to PingCRM
Go to → + Add Connection → choose MSG91 → paste API Key + Sender ID → click Test Connection → Save.
7
Add to Vercel env vars
MSG91_API_KEY = your Auth Key. See the

Push Notification Setup
PingCRM supports Firebase FCM (Android + Web) and Apple APNs (iOS). Set up both for full coverage, or use OneSignal as a single cross-platform gateway.
🔥
FCM — Firebase Cloud Messaging
Android apps + Web Push (Chrome, Firefox, Edge)
▼
1
Create a Firebase project
Go to console.firebase.google.com → Add project → name it (e.g. AcmeCRM) → Continue.
2
Get your Server Key (legacy) or Service Account
Project Settings → Cloud Messaging tab → Server key (copy it). Alternatively, for the newer HTTP v1 API: Project Settings → Service accounts → Generate new private key → download the JSON file → paste its contents in PingCRM.
3
Copy Sender ID
Project Settings → Cloud Messaging → Sender ID (a 12-digit number). Needed for the Web Push manifest.
4
Generate VAPID keys for Web Push
Project Settings → Cloud Messaging → Web configuration → Generate key pair. Copy the Public key (starts with BEl…). This goes into your web app's service worker.
5
Add SDK to your Android app
Add Firebase to your Android project via the Firebase console wizard (downloads google-services.json). Add the FCM dependency in build.gradle:
implementation 'com.google.firebase:firebase-messaging:23.4.0'
Then call PingCRM's ingest endpoint when you get a new FCM token.
6
Add to PingCRM
→ Add Connection → Push tab → FCM → paste Server Key, Sender ID, VAPID Key → Save.
⚠️ SDK token registration: Your app must send FCM device tokens to PingCRM's /api/ingest-event endpoint when the token is generated or refreshed. Without this, PingCRM has no way to reach the device. 
POST /api/ingest-event
{
  "workspace_id": "00000000-0000-0000-0000-000000000001",
  "user_id": "user_123",
  "event": "push_token_registered",
  "properties": { "fcm_token": "ey..." }
}
🍎
APNs — Apple Push Notification Service
iOS, iPadOS, macOS apps · Requires Apple Developer account ($99/yr)
▶
1
Apple Developer account
Enroll at developer.apple.com ($99/year). Your app Bundle ID must be registered.
2
Create an APNs Auth Key (.p8) — recommended
Developer portal → Certificates, IDs & Profiles → Keys → + (add) → check Apple Push Notifications service (APNs) → Continue → Download. This file can only be downloaded once — save it securely.
Also note your Key ID (10-char string, shown on key list) and Team ID (top-right of developer portal).
3
Enable Push in your app's Bundle ID
Identifiers → select your App ID → Capabilities → enable Push Notifications → Save.
4
Add to PingCRM
→ Push tab → APNs → paste .p8 contents, Key ID, Team ID, Bundle ID → choose Production or Sandbox → Save.
5
Register device tokens in your iOS app
In AppDelegate.swift, implement didRegisterForRemoteNotificationsWithDeviceToken and send the token to PingCRM's ingest endpoint:
POST /api/ingest-event
{
  "workspace_id": "...",
  "user_id": "user_123",
  "event": "apns_token_registered",
  "properties": { "apns_token": "abc123..." }
}
